# Why POF

An organization's operation is spread across systems: who does what in
one, the procedures in another, the approval rules in a third, the goals
in a spreadsheet, the channels and integrations in each tool's settings.
None of it can be taken somewhere else whole, and no agent can read it
whole either.

POF treats the organization as **data first**: one bundle of plain
files that any system can write, any other can import, and a person or
an agent can read as it is.

## The organization, not one system's view of it

The core types are concepts of an organization, not of a product: every
organization has [roles](/format/roles), knows how to do things
([skills](/format/skills)), decides who handles what
([policies](/format/policies)), commits to
[objectives](/format/objectives), repeats
[routines](/format/routines), talks through
[channels](/format/channels) and reaches other systems through
[connections](/format/connections). Any system that holds one of them
writes it with the same shape.

What is particular to one system, it writes as an
[extension](/format/extensions), under its own namespace. The core stays
small and stable; the extensions carry everything else without asking
the spec for room.

## Readable without the app

Every piece is a Markdown file a person can open in a text editor. Its
fields are YAML. Its relations are paths you can follow with `cd`. There
is no binary format to decode and no id to look up in a database that is
not there.

<Callout type="info">
  If the system that wrote a bundle disappears, the bundle still says
  everything it said the day it was written.
</Callout>

## Portable means importable

A bundle is meant to be imported, not only archived. That is why:

- identity is the folder, so a piece arrives as the same piece in any
  system;
- relations are paths, so they survive new ids;
- the history is optional but exact, so an organization can arrive with
  its past or start fresh at the import;
- access state stays out, so moving a bundle never moves a credential.

## Diffable

A writer produces the same bytes for the same content. Two exports of an
organization, a week apart, can be compared with `diff`: what changed in
a role, which rule was added to a policy, which objective moved. The
history inside the bundle says who changed it and why.
