# Skills

A Skill is one thing the organization knows how to do, written so that
whoever reads it (a person or an agent) can do it without asking. It has
the same shape as an [Agent Skill](https://agentskills.io): a folder with
a `SKILL.md` whose `name` and `description` tell an agent when to load
the rest.

`skills/<slug>/SKILL.md`, with its files under `files/`.

## Fields

Besides the [common fields](/format/documents#frontmatter-of-a-piece):

| Field | Required | Notes |
|---|---|---|
| `type` | Yes | `Skill`. No `kind`. |
| `description` | Yes | When to use it. This is what an agent reads before deciding to load the skill. |
| `domain` | Yes | The area it belongs to (`ventas`, `soporte`). A role's `skill_domains` refer to it. |
| `category` | No | A free label for grouping skills. |
| `license` | No | The skill's license, when it comes from elsewhere. |
| `allowed_tools` | No | The tools the skill asks for, as a list. |
| `source_repo`, `source_path`, `source_ref`, `source_sha` | No | Where an imported skill came from: the repository, the folder in it, the ref asked for and the commit read. |

Links: `used_by` toward the [roles](/format/roles) that use it.

## Body

The body is the skill's **instructions**, in free Markdown.

## Example

```yaml filename="skills/cotizar/SKILL.md"
---
type: Skill
title: Cotizar
name: cotizar
description: Cuando un cliente pide precio de uno o más productos.
domain: ventas
links:
  - role: used_by
    to: roles/ventas/vendedor
    created_at: 2026-10-18T15:25:01.610Z
created_at: 2026-10-18T15:25:01.610Z
updated_at: 2026-10-18T15:25:01.610Z
created_by: user:equipo@acme.example
updated_by: user:equipo@acme.example
---
1. Confirmá productos y cantidades.
2. Armá la cotización con la lista de precios vigente.
3. Mandala y agendá el seguimiento a los dos días.
```

## Files

A skill can carry files: a script, a template, a reference. Each one is a
`File` in `files/<nn>-<slug>.md`, with the file's content as the body.

| Field | Required | Notes |
|---|---|---|
| `type` | Yes | `File`. |
| `position` | Yes | Its order inside the skill. |
| `path` | Yes | Where the file lives inside the skill (`scripts/check.py`). Letters, digits, `.`, `_`, `-` and `/`; never `SKILL.md`. |
| `content_type` | Yes | Its media type. |
| `encoding` | Yes | `utf8` for text, `base64` for anything else. |
| `size_bytes` | No | Its size. |
