# Glossary

**Annotation**
A note left on a piece, in its `annotations/` folder. See
[Documents and links](/format/documents#annotations).

**Bundle**
A whole organization as one zip or folder of Markdown files, with a
`POF.md` manifest at its root. See [The bundle](/format).

**Commit**
One change to the organization, made by one actor at one moment, listed
in `COMMITS.md`. See [History](/format/history).

**Core**
The seven types every organization has: Role, Skill, Policy, Objective,
Routine, Channel and Connection. See [The bundle](/format#the-core).

**Extension**
Another system's data inside a bundle, in `extensions/<namespace>/`,
with its own `EXTENSION.md` and namespaced types (`hub.deal`). See
[Extensions](/format/extensions).

**Frontmatter**
The YAML block at the top of every document, between `---` lines, with
its structured fields, apart from its Markdown body.

**Kind**
A piece's type within its family's catalog, written only in families
with more than one: Objective, Channel and Connection.

**Link**
A relation from one piece to another, written as a `role` and a path
(`to`). See [Documents and links](/format/documents#links).

**Manifest**
`POF.md`: what the bundle is, which revision of the spec it follows and
which extensions it carries. See [The manifest](/format/manifest).

**MCP (Model Context Protocol)**
An open protocol for how an agent connects to tools and resources. See
[POF vs. MCP vs. Agent Skills](/concepts/pof-vs-mcp-vs-skills).

**OKF (Open Knowledge Format)**
The frontmatter convention POF documents conform to: `type` required,
`title`, `description` and `tags` as its recommended fields.

**Piece**
One document of the core, in its own folder: a role, a skill, a policy,
an objective, a routine, a channel or a connection.

**Revision**
The version of this spec a bundle follows, named by its date. The
current one is `2026-10-16`.

**Slug**
The lowercase, hyphenated name of a folder (`aprobacion-de-compras`).
It is a piece's `name` and its identity in the bundle.

**Subentity**
An item that belongs to a piece, in a folder of it: a policy's rules, an
objective's key results, a skill's files.
